# ctl demo Zephyr project

If you install the Zephyr on your Linux system into the std. folders you just need to open the console at the ctl folder. run

```console
source build_me.sh
```

and after setup the make project via

```console
cmake ..
```

build it via

```console
make -j
```

and here you are with a little demo.
